# Gammorph Production — Portfolio

Single-page portfolio site for Gammorph Production (Editor · Colorist · VFX Artist).
Plain HTML/CSS/JS — no build step, no dependencies.

## Files

| File | Purpose |
|------|---------|
| `index.html` | The whole website |
| `README.md` | This file |
| `.gitignore` | Files Git should ignore |
| `.nojekyll` | Tells GitHub Pages to serve files as-is |

## Run locally

Open `index.html` in your browser.

## Put it on GitHub

1. Create a new empty repository on github.com (e.g. `gammorph-portfolio`).
2. In this folder, run:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/gammorph-portfolio.git
git push -u origin main
```

## Publish it free with GitHub Pages

1. On GitHub, open the repo → **Settings** → **Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Choose branch `main` and folder `/ (root)`, then **Save**.
4. After a minute, the site is live at `https://YOUR-USERNAME.github.io/gammorph-portfolio/`.

## Customise

- Replace the placeholder cards in the "Selected Work" section with your real projects.
- Update the bio in the About section and the email/social links in the footer.
